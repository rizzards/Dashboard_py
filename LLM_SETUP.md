# LLM Financial Analyst Setup

## Overview

The `llm_financial_analyst.py` module provides AI-powered financial analysis using Azure OpenAI (gpt-4o). It analyzes the comparison text generated by the dashboard and provides professional insights without hallucinating numbers.

## Architecture

**Direct Azure OpenAI Integration with gpt-4o** - Uses the official OpenAI Python SDK with Azure endpoints for straightforward LLM calls.

**Key Design Principles:**
- Feeds the entire `comparison_text` (from `generate_enhanced_comparison_text_updated()`) directly to the LLM
- Uses gpt-4o model for improved reasoning and accuracy
- Implements anti-hallucination safeguards via explicit system prompts
- Lower temperature (0.3) for more deterministic, fact-based analysis
- Only references numbers and facts explicitly stated in the comparison text

**Why not LlamaIndex?** For this use case, we don't need:
- Document indexing/retrieval (no large document corpus)
- Complex RAG pipelines (analysis is based on structured metrics already in comparison_text)
- Multi-step reasoning chains

LlamaIndex could be added later if you want to:
- Index historical financial reports
- Build a knowledge base of financial events
- Enable conversational analysis with memory

## Setup Instructions

### 1. Install Dependencies

```bash
pip install -r llm_requirements.txt
```

### 2. Configure Azure OpenAI

Set environment variables:

```bash
# Windows (Command Prompt)
set AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
set AZURE_OPENAI_KEY=your-api-key-here

# Windows (PowerShell)
$env:AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
$env:AZURE_OPENAI_KEY="your-api-key-here"

# Linux/Mac
export AZURE_OPENAI_ENDPOINT="https://your-resource.openai.azure.com/"
export AZURE_OPENAI_KEY="your-api-key-here"
```

Or create a `.env` file:

```
AZURE_OPENAI_ENDPOINT=https://your-resource.openai.azure.com/
AZURE_OPENAI_KEY=your-api-key-here
```

### 3. Enable in Application

In `application.py`, uncomment the LLM analysis section (around line 1284):

```python
# ========== LLM FINANCIAL ANALYSIS PLACEHOLDER ==========
from llm_financial_analyst import analyze_comparison_with_llm

llm_analysis = analyze_comparison_with_llm(comparison_text)

# Append LLM analysis to comparison text
comparison_text = comparison_text + "\n\n" + "="*60 + "\n"
comparison_text = comparison_text + "AI FINANCIAL ANALYSIS:\n" + "="*60 + "\n\n"
comparison_text = comparison_text + llm_analysis
# ========================================================
```

## Usage Example

The LLM will automatically generate analysis when comparing two dates in the Comparison tab. The analysis will appear in the "Comparison Notes" section with:

1. Executive Summary: Concise overview of key changes and significance
2. Key Drivers: Interpretation of what is driving changes based on provided data
3. Metric Relationships: Analysis of how Amount, Income, and Ratio changes relate
4. Implications: Professional considerations and action items for stakeholders

## Customization

### Adjust Model Parameters

In `llm_financial_analyst.py`, modify the `analyze_comparison_text()` method:

```python
analyst.analyze_comparison_text(
    comparison_text,
    max_tokens=1000,     # Adjust response length (default: 1000)
    temperature=0.3      # 0=deterministic, 1=creative (default: 0.3 for reduced hallucination)
)
```

### Change Deployment Model

```python
analyst = FinancialAnalystLLM(
    deployment_name="gpt-4o"  # or "gpt-4", "gpt-35-turbo", etc.
)
```

## Cost Considerations

- GPT-4o: ~$0.015-0.03 per comparison analysis (more cost-effective than GPT-4)
- GPT-4: ~$0.03 per comparison analysis
- GPT-3.5-Turbo: ~$0.002 per comparison analysis
- Analysis is only generated when viewing Comparison tab
- gpt-4o recommended for best balance of quality, speed, and cost

## Troubleshooting

**Error: "Azure OpenAI endpoint and API key must be provided"**
→ Set environment variables or pass to constructor

**Error: "Resource not found"**
→ Check deployment name matches your Azure OpenAI deployment

**Slow responses**
→ Consider using gpt-35-turbo for faster, cheaper analysis
